## 1. 如何试玩

打开 `Assets/Scenes/main.unity`，点击 Unity 的 Play。等待项目原有的资源初始化完成，开始菜单会自动出现。点击“开始游戏”进入关卡。

- 鼠标在桌面内移动：瞄准。
- 在桌面内按住左键：蓄力；松开：出杆。移出桌面后松开取消出杆。
- 右键：取消蓄力。Esc：蓄力时取消，其他可操作状态切换暂停。
- 目标提示：隐藏或显示内切、外接虚线圆。
- 暂停/继续：冻结并恢复本局；失焦自动暂停，需要手动继续。
- 重新开始：恢复出生位置、初始大小、增长趋势、道具及三杆机会。
- 返回菜单：销毁当前主界面和白球，清理本局。
- 退出：Editor 中停止 Play；Player 代码路径调用 Application.Quit。

初版为鼠标操作，采用横版画布，参考尺寸 1672×941；验收 Game View 为 1920×1080。尚未构建独立 Player 或验证移动端操作。

## 2. 本版已实现

| 内容 | 当前行为 |
|---|---|
| 开始菜单 | StartUI 全屏；开始、设置、退出可用；存档和制作详情禁用占位 |
| 主界面 | MainUI 全屏；桌面、白球、三角形、目标圆、翻转道具及状态侧栏 |
| 设置 | SettingsUI 非全屏弹窗，原菜单保留在背景；四个独立图标及音量滑条 |
| 音量项 | Music、Sound、UISound、Voice；Voice 显示为“声音”，使用扬声器图标 |
| 音量开关 | 点击图标改变对应 AudioModule 开关，保留数值；关闭时图标灰显、滑条禁用 |
| 击球 | 瞄准、蓄力、出杆、取消合并在 BallShootComponent |
| 模拟 | 直线减速、固定计划路程、半径增长/缩小与上下限合并在 BallSimulationComponent |
| 判定 | 静态内切/外接；连续运动区间查找最早命中，提交命中状态并停球 |
| 道具 | 球与道具圆周接触，本杆只触发一次，翻转半径变化方向并重查剩余时间 |
| 尝试循环 | 有效出杆扣一次；失败有剩余机会则自动复位；第三次仍可成功；最终失败锁定出杆 |
| 数据 | 两张 Luban 表，异步准备 bytes，生成类型转只读业务数据，初始化前校验 |
| 生命周期 | 重复进入、返回、取消异步进入；已加载和未完成绑定的窗口均安全清理 |

同刻事件顺序为越界 → 成功 → 道具 → 自然停止。几何判定基于逻辑坐标与半径；UI 不参与规则计算。缩小中的球显示淡蓝色，目标命中后保留位置和大小。

## 3. 实际代码位置

业务根目录为 `Assets/GameScripts/HotFix/GameLogic/`。

```text
Module/
  GameModule/GameManager.cs       单例入口、进入/返回/退出和清理
  LevelModule/LevelManager.cs     配置准备、读取、校验和关卡生命周期
  BallModule/BallManager.cs       单白球管理
Core/
  Ball/                          BallBase、WhiteBall、BallConfigData
    Components/                  BallComponentBase、BallShootComponent、BallSimulationComponent
  Level/                         BilliardsLevelData、BilliardsBoardView、BilliardsGeometryGraphic
  Rules/                         BilliardsGoalJudge、PolynomialRoots
  Session/                       BilliardsSession、BilliardsSessionRunner、BilliardsUISnapshot
  Events/                        BilliardsEvents
UI/                              StartUI、MainUI、SettingsUI
```

球基类保留初始化、显示、位置与大小同步及复位；功能采用组合。判定是独立规则类，由 Session 协调，没有放进球组件。单个翻转道具由关卡视图显示、Session 管理状态、判定器查询接触，当前没有为它额外创建管理器或空的 Item 分类。

入口接入现有 `GameApp.StartGameLogic()`。窗口使用现有 Window、UIBindComponent、GameEvent 与 AddUIEvent；运行时依赖 Prefab 的序列化绑定。MainUI 的资源地址为 GameMainUI，保留项目已有示例 MainUI.prefab。GameLogic.asmdef 增加已有 Unity.InputSystem 程序集引用。

## 4. 资源与制作工具

已通过 Unity Pipeline 导入开始菜单和当前设置美术；主界面复用已导入的像素资源。三份新 Prefab 位于 `Assets/AssetRaw/UI/StartUI.prefab`、`GameMainUI.prefab`、`SettingsUI.prefab`。球与桌面组件在主界面 Prefab 中制作并绑定，运行时不临时补组件。

新导入美术位于 `Assets/AssetRaw/UIRaw/Raw/MathBilliards/Menu/` 和 `Settings/`。Sprite 使用 Point 过滤、不启用 mipmap，透明资源保留透明通道。桌面与侧栏使用九宫格边框，目标图形使用 CanvasRenderer 绘制。球贴图 8px 透明留白已补偿，使可见直径与逻辑直径一致。

中文字体为 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)，字体和 OFL 许可位于 `Assets/AssetRaw/Fonts/`。

`Tools/InitialDemoAuthoring.cs` 是通过 Pipeline run_script 使用的编辑器制作工具，不进入运行时程序集；已有同名 Prefab 时拒绝覆盖。它依赖已设置的 Sprite 导入参数。

为匹配横版设计，main 场景 UICanvas 的 CanvasScaler 改为 1672×941。原工程关闭域重载时重复 Play 会出现既有 FSM/对象池重复初始化异常，已恢复 Play 时的域重载；未修改框架模块实现。

## 5. Luban 配置与修改流程

源工程位于仓库根目录 `Configs/GameConfig/`，复用既有工程及导表脚本。

| 内容 | 路径/成员 |
|---|---|
| 球参数源表 | `Datas/billiards_ball.xlsx`，id=1 |
| 关卡源表 | `Datas/billiards_level.xlsx`，id=1，引用 ballConfigId=1 |
| 表注册 | `Datas/__tables__.xlsx`：billiards.TbBall、billiards.TbLevel |
| 导表 | `gen_code_bin_to_project_lazyload.bat`；自动执行设置 AI_MODE=1 |
| 生成类型 | `UnityProject/Assets/GameScripts/HotFix/GameProto/GameConfig/` |
| 生成数据 | `UnityProject/Assets/AssetRaw/Configs/bytes/billiards_tbball.bytes`、`billiards_tblevel.bytes` |
| 实际访问 | `ConfigSystem.Instance.Tables.TbBall`、`TbLevel` |
| 加载器源模板 | `Configs/GameConfig/CustomTemplate/ConfigSystem.cs` |

Luban 使用[官方 v4.10.2 发布包](https://github.com/focus-creative-games/luban/releases/tag/v4.10.2)，已放入既有 `Tools/Luban/` 位置。下载归档 SHA-256 为 `785b53b570c918827d314ef78caa180ca1c55bc252ebc1e921a6dc0760317e8d`。

修改 Excel 后在 Configs/GameConfig 中运行上述导表脚本，等待 Unity 导入/编译完成，再重新 Play。不要手改生成 C# 或 bytes。ConfigSystem 缓存本次准备的数据，当前不提供局中热更新配置。

实际加载分两层：LevelManager 用 GameModule.Resource 异步加载两张 TextAsset，复制 bytes 后配对释放资源；GameProto 内的 ConfigSystem.Initialize 接收内存字典，仅同步解析，不引用 GameLogic 或 UniTask。先修改模板，再由导表复制模板；生成结果不是手工维护文件。

当前默认参数：三杆机会、计划路程 2.5、蓄满时间 1.5 秒、速度 3～12、出球半径 0.3～2.4、半径限制 0.1～3、变化速度 0.8、模拟步长 1/120 秒、目标容差 0.08。单关布局采用既有设计文档的验收数据。
