初版已导入当前四个图标及面板，并制作 Assets/AssetRaw/UI/SettingsUI.prefab。非全屏弹窗、四类滑条和点击图标开关已对接 GameModule.Audio，12 项控制检查通过；Voice 使用“声音”与扬声器图标。实际截图和验证边界见[初版验收记录](数学桌球-初版验收/初版实施与验收记录.md)。本次未增加音频素材。

## 1. 本次确认的范围

开始菜单的设置按钮打开 `SettingsUI`。设置是居中弹窗，开始界面仍在背后显示；关闭设置后继续显示原来的开始界面。开始界面与主界面均为全屏窗口。

设置弹窗提供项目现有的四类音量行与一个关闭按钮。每行包含独立可点击图标，点击图标切换该分类的声音开关；滑块负责音量大小。存档和制作详情继续占位。本阶段从开始界面打开设置，不增加主界面设置入口，不加入总音量、额外的全局静音开关、恢复默认、画质、按键或语言选项。初版已接入上述范围。

## 2. 根据实际项目确定音量项

已核对 `Assets/TEngine/Runtime/Module/AudioModule/AudioType.cs`、`IAudioModule.cs`、`AudioModule.cs` 与 `AudioCategory.cs`。现有分类为 Music、Sound、UISound、Voice，统一通过 `GameModule.Audio` 访问。本项目按用户确认将 Voice 的界面显示名统一为“声音”，代码分类和接口名称保持原样。

| 显示名称 | 分类 | 音量属性 | 分类开关 | 使用内容 |
|---|---|---|---|---|
| 背景音乐 | Music | `MusicVolume` | `MusicEnable` | 菜单和游戏背景音乐 |
| 游戏音效 | Sound | `SoundVolume` | `SoundEnable` | 击球、目标成功、道具等玩法声音 |
| 界面音效 | UISound | `UISoundVolume` | `UISoundEnable` | 按钮与界面操作声音 |
| 声音 | Voice | `VoiceVolume` | `VoiceEnable` | Voice 分类对应的声音；没有该类素材时仍保留此项 |

项目另外有全局 `Volume` 和 `Enable`，本次不展示第五条滑块。四类滑块不修改全局值；全局静音时分类值仍可调整，但不会因此解除全局静音。默认值读取当前 AudioModule 的配置与状态，不把效果图中的 80%、70%、60%、50% 写成运行默认值。

## 3. 全屏与弹窗约定

| 窗口类 | UI 层 | 资源地址（拟定） | fullScreen | 表现 |
|---|---|---|---|---|
| `StartUI` | UILayer.UI | StartUI | true | 全屏开始界面 |
| `MainUI` | UILayer.UI | GameMainUI | true | 全屏主界面；保留已有示例 MainUI.prefab |
| `SettingsUI` | UILayer.Top | SettingsUI | false | 非全屏设置面板，背后界面保持可见 |

窗口名继续省略 Billiards 前缀。实施时可采用 `[Window(UILayer.Top, "SettingsUI", fullScreen: false)]`，并核查资源地址唯一性。窗口脚本放在 `GameLogic/UI/`，生成代码按当前生成器配置输出到 UI/Gen；管理器与 Core 的分类遵循[当前目录归属约定](../架构设计/数学桌球-脚本目录归属约定.md)。

设置窗口可以有铺满 Canvas 的半透明遮罩，以压暗背景并拦截输入；这不改变窗口的 `fullScreen: false`。居中的内容面板不拉伸到屏幕四边。遮罩点击不关闭窗口，仅关闭按钮关闭；弹窗显示时不得点击到背后的开始、退出等按钮。

## 4. 布局与节点

参考画布 1280×720，沿用当前 Canvas Scaler，不修改项目全局画布配置。内容面板外框建议约 720×520，水平和垂直居中，小屏按等比缩放保留边距。

面板从上到下为标题“设置”、四条音量行、关闭按钮。每行按可点击图标、标签、滑块、百分比排列；四条滑块宽度一致，百分比右对齐。四种图标分别为音符、白球碰撞、点击光标、扬声器。“声音”使用带两道声波的扬声器，匹配深蓝粗描边、暖金色和象牙白的像素风格；正式资源为 settings_icon_voice_v2.png。图标开启时使用正常亮色，关闭时变灰，旁边的独立状态文字显示“开/关”，图标仍可点击。标题约 36，标签和百分比约 24；具体随现有字体和画布实测调整。参考效果图是视觉示意，最终文字用 Unity 文本组件渲染。

```text
SettingsUI
├── m_img_Mask                    全屏输入遮罩，半透明深蓝
└── m_rect_Panel                  居中面板
    ├── m_img_PanelBackground     空白面板图片
    ├── m_text_Title              设置
    ├── MusicRow                  音符图标 Button / 开关文字 / 背景音乐 / Slider / 百分比
    ├── SoundRow                  碰撞白球 Button / 开关文字 / 游戏音效 / Slider / 百分比
    ├── UISoundRow                点击光标 Button / 开关文字 / 界面音效 / Slider / 百分比
    ├── VoiceRow                  扬声器 Button / 开关文字 / 声音 / Slider / 百分比
    └── m_btn_Close               关闭
```

上述为示意层级；滑块、文本的最终绑定前缀按实际 ScriptGenerator 支持的组件映射核对，不把示意名称当成已生成绑定。四个 Slider 的可调范围采用 1～100 的整数，步长 1，写入音频时转换为 `百分比 / 100f`；静音由图标关闭完成，以保留非零音量并保证重新开启能出声。音频配置里的极小值显示为 1% 时，仅规范化展示，不在打开窗口时反写。轨道、填充、手柄分别为独立 Image。图标建议 48×48，Button 点击区至少 48×48；滑块有效点击区高度至少 40。

## 5. 操作和生命周期

1. StartUI 设置按钮调用 `GameModule.UI.ShowUIAsyncAwait<SettingsUI>()`。窗口存在或正在打开时拒绝重复请求；打开失败恢复按钮可用，不关闭 StartUI。
2. 首次创建时绑定四个图标 Button、四个 Slider 和关闭按钮的回调；每次 `OnRefresh` 读取现有分类音量与开关状态，更新图标、“开/关”、滑块与百分比。使用 `SetValueWithoutNotify` 填充初值，避免打开窗口时反写音频。
3. 图标点击切换对应分类的 Enable，不改音量属性。关闭后滑块变灰且不可拖动，保留百分比；重新开启后恢复可拖动。图标 Button 始终可用，不能随滑块一起禁用。
4. 开启状态下拖动滑块，更新对应百分比并即时应用该分类音量。四类互不影响，不等待关闭后统一提交。
5. 关闭调用 `GameModule.UI.CloseUI<SettingsUI>()`，仅关闭弹窗，保留音量、各分类开关和开始界面。销毁时移除手工注册的 Unity UI 监听；不得重复注册或留存旧窗口回调。

不新增 AudioManager、SettingsManager 或设置单例。四类音频状态继续由现有 AudioModule 持有，SettingsUI 只负责展示与请求。GameManager、LevelManager、BallManager 不保存音量。当前应用内关闭重开设置、开始游戏或重开本局不重置音量；跨应用启动保存留待后续需求，不加入 PlayerPrefs 或存档写入。

## 6. 图标开关与恢复声音

现有四类音量 setter 都把输入限制到 `0.0001～1` 并转换为分贝。图标开关直接对应 MusicEnable、SoundEnable、UISoundEnable、VoiceEnable；关闭时不把音量写成 0，所以例如关闭 80% 的音乐后，仍能记住 80%，重新开启继续使用该值。不要把开关状态推导为“音量是否大于 0”。

`AudioCategory.Enable = false` 会停止该分类所有 agent，关闭后禁止新的分类播放。游戏音效、界面音效、声音重新开启时等待下一次正常播放请求，不自动重播刚才已结束的声音。

MusicEnable 的 setter 同样会停止当前音乐；设为 true 只恢复分类与 Mixer，不会自动重新播放被 Stop 的曲目。后续实施开启音乐时，要通知负责当前背景音乐的播放入口，必要时补播该入口持有的当前 BGM，并避免重复叠加。补播从曲目起点播放，不要求保存播放进度。尚无 BGM 素材时只恢复允许播放状态，不虚构音频资源。SettingsUI 不保存音乐资源、不管理播放列表、不新增 AudioManager。

若外部配置已把音乐置为 -80 dB，MusicEnable getter 会返回 false。用户点图标开启前将该分类低于 1% 的音量规范化为 1%，再设 Enable 为 true，避免开关已开却仍是 Mixer 静音。此动作仅发生在用户主动开启时，初始化不反写。全局 Volume/Enable 保持不变。

## 7. 美术交付与后续接入

资源包包含新生成的透明空白面板、四个独立分类图标、带图标的完整设置效果图，以及从已有像素包原样复用的轨道、填充、手柄和关闭按钮两种状态。图标关闭态用 Image 变灰与独立“关”文字呈现，不另烘焙四张关闭图。效果图不作为整张可交互 UI 导入；实际界面使用拆分图片与文本、Slider、Button 组合。

面板外侧 alpha 透明，内部不透明；遮罩使用 Image 色值，不需要另出一张黑图。面板按原比例缩放，角部保留，不直接猜测九宫格边界。已有小组件适配缩放方式见资源说明。

本次资源均存放在 Docx 美术资源目录。后续实现再经 Unity Pipeline 导入、检查 Sprite Importer、GUID、收集配置、Prefab 与生成绑定；本次没有导入 Assets，也没有创建代码、Prefab 或 .meta。

## 8. 后续实施验收

- StartUI 与 MainUI 标记 fullScreen 为 true；SettingsUI 为 false，内容面板保留周围背景与边距。
- 打开设置只出现一个窗口，背后菜单可见且无法操作；关闭后菜单可正常操作。
- 四项与实际 AudioType 一一对应，打开读取真实状态，百分比与滑块一致，四类互不影响。
- 每类图标分别检查点击关闭、再次开启与快速连续点击，开关只影响对应分类；关闭后图标变灰且标注“关”，滑块不可拖动但图标仍可操作，音量值不丢失。
- 每类分别检查 1%、50%、100% 与窗口关闭重开；禁用后新播放请求被禁止，重新开启音乐能由原播放入口补播，且不产生多条重复 BGM。
- 初始化不触发音量回调；反复打开关闭不重复监听，不重置已调整值；开始游戏和本局重开不改音量。
- 全局静音保持原状态；无声音素材、音频系统不可用等情况下界面不异常，系统不可用时禁用滑块且不虚报应用成功。
