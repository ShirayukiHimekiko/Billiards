# 数学桌球：小球成长机制与二十关再适配方案

日期：2026-10-07  
任务等级：L3 功能调整  
状态：已按统一成长机制完成作者数据、源配置与 Luban 产物更新；尚未执行关卡回放

## 1. 用户确认后的机制前提

白球从关卡配置的原始半径开始。出杆时不再按力度重设半径，力度只影响本杆速度、预计路程和成长速度：

```text
growRate(power) = Lerp(growRateMin, growRateMax, power)
radius(t) = shotStartRadius + growRate(power) * t
```

其中：

- 第一杆的 `shotStartRadius` 为 `LevelBall.spawnRadius`。
- 后续击球从上一杆真实终态半径继续，不回到出生半径；犯规重生或重开关卡才恢复出生半径。
- 每次出杆恢复为增长趋势。
- 翻转后从触发瞬间的真实半径开始，按固定 `shrinkRate` 缩小；同杆再次翻转后恢复本杆由力度确定的成长速度。
- 达到球配置的最小或最大半径、贴边增长受阻或球停止运动时，尺寸不再继续变化。

## 2. 已确认的不一致

### 2.1 运行时已经是新机制

`PhysicsWorld.Shoot` 当前不会改写白球半径，会通过 `Lerp(growRateMin, growRateMax, power)` 设置本杆成长速度；`RadiusRate` 再按增长或缩小趋势返回实际半径变化率。

### 2.2 关卡作者脚本仍按旧机制

`Tools/Campaign.py` 当前存在以下旧假设：

- `shot_radius(power)` 把每杆起始半径计算为 `0.25 + 0.75 × power`。
- `growing_radius`、`contact_position`、`route` 和 `radius_on_route` 把成长速度固定为 `0.12`。
- 多杆路线会为每杆重新计算力度半径，没有从上一杆终态半径继续。
- 翻转路线按固定正负 `0.12` 推导，未使用本杆力度对应的成长速度。

这与运行时机制不一致。现有图形目标仍能通过历史回放，主要依赖目标容差和既有路线的偶然兼容，不能作为继续局部修改的依据。

### 2.3 配置生成脚本仍是旧字段

`Tools/ConfigureGameConfig.py` 仍定义单一 `growRate`，而当前 Luban 类型和 Excel 表已经是 `growRateMin`、`growRateMax`、`shrinkRate`。若直接重跑旧脚本，会覆盖当前配置结构或生成错误数据。

## 3. 成长曲线建议

全部关卡统一使用一条白球成长曲线，不再按关卡拆成不同速率档位。同样力度在不同关卡必须产生相同成长速度，玩家才能建立稳定认知。

建议第一轮保留当前曲线：

| 参数 | 数值 | 说明 |
|---|---:|---|
| spawnRadius | 0.28 | 全关统一出生半径 |
| growRateMin | 0.06 | 零力度时每秒成长量 |
| growRateMax | 0.18 | 满力度时每秒成长量 |
| shrinkRate | 0.12 | 翻转后的固定缩小速度 |
| radiusMin | 0.15 | 允许最小半径 |
| radiusMax | 1.60 | 允许最大半径 |

保留该曲线的理由：

- 中等力度 `0.5` 的成长速度正好为旧基准 `0.12`，便于平稳迁移。
- 从 `0.28` 开始，无碰撞完整滚动时，零力度最终约为 `0.40`，满力度最终约为 `1.09`，力度差异明确。
- 在相同短距离内，高力度虽然成长更快，但移动也更快，半径差异不会突然失控；完整路程和多次反弹后差异才逐渐放大，符合“力度同时决定路线和成长”的玩法。
- 先固定成长曲线、再重做关卡，能把关卡问题与参数问题分开。若同时修改曲线和全部布局，无法判断失败来自哪一侧。

白球 ID 1 作为唯一正式配置供二十关使用。ID 3 先保留但不再被关卡引用，避免在本轮无必要地删除配置记录；确认新关卡稳定后可另行清理。

## 4. 二十关重做原则

所有关卡都从真实公式重新构造，不沿用旧脚本推导出的半径：

1. 从 `spawnRadius=0.28` 建立第一杆状态。
2. 根据该杆力度计算速度、基准路程、减速度和 `growRate(power)`。
3. 按目标距离或实际事件时间计算球的真实半径。
4. 球碰撞、库边、几何门、道具和球洞均按事件发生时半径重新确定位置。
5. 一杆结束后保留终态位置、半径和关卡进度，作为下一杆输入。
6. 遇到翻转时建立分段半径函数，不能用单一平均速度近似整杆。
7. 每关重新记录参考方向和力度；旧参考解仅作布局意图参考，不继续宣称适配新机制。

## 5. 分阶段适配内容

### 5.1 第 1～5 关：基础教学

- 第 1 关使用低力度、短距离，让玩家首次看到缓慢成长。
- 第 2 关通过更大力度体现更快成长，同时保持直线进洞，避免混入角度难题。
- 第 3 关按真实接触半径重算斜碰瞄准点，明确教授“力度改变尺寸，也改变碰撞几何”。
- 第 4 关按真实碰撞半径重算黑球入射点和借边路线。
- 第 5 关必须从第一杆的真实终态半径继续构造第二杆，不能重新按力度生成半径。

### 5.2 第 6～8 关：尺寸目标教学

- 第 6、7 关根据出生半径和目标到达时间重算内切、外接三角形尺度。
- 第 8 关分别计算翻转前增长段和翻转后缩小段，重新摆放两个目标；不能沿用固定 `±0.12` 的旧推导。
- 保持较宽容差，让玩家先理解力度与尺寸关系，不把入门关做成精确蓄力窗口。

### 5.3 第 9～10 关：机制组合

- 第 9 关改为正式白球配置 ID 1，并重新计算两杆连续成长后的起始半径、图形尺度与反弹路线。
- 第 10 关从真实翻转终态进入第二、第三杆，重新确定三个黑球位置及三个球洞解锁目标。

### 5.4 第 11～15 关：多杆路线与图形组合

- 第 11、12 关按跨杆保留半径重算后续黑球位置，避免白球后期过大时与出生布局重叠或提前碰撞。
- 第 13～15 关分别从上一杆真实终态推导下一个图形目标，不再让每个目标假设白球从新的力度半径开始。
- 准备杆与正式进球杆分开的关卡，准备杆结束半径必须成为下一杆真实起点。

### 5.5 第 16～20 关：翻转与综合规划

- 第 16、19 关按“力度成长速度 → 第一次翻转 → 固定缩小速度 → 下一杆恢复新力度成长速度”重算。
- 第 17、20 关包含同杆两次翻转，需要保存三个连续区段：增长、缩小、恢复增长。
- 第 18 关重新检查四杆连续成长后的尺寸上限、台边空间和后续碰撞线路。
- 第 20 关所有准备、解锁、反弹和四球路线均从同一个连续状态链构造，不能单独计算每杆。

## 7. 设计原则

- **单一职责**：运行时只执行统一物理规则，关卡差异全部由配置表达。
- **开闭原则**：不为某一关在物理代码中添加例外判断。
- **组合复用**：继续复用现有球、图形、道具、球洞和确定性物理世界。
- **数据一致性**：作者脚本、Excel 源表、Luban 生成物和参考解使用同一组公式与参数。
- **可追溯性**：每个目标半径都能追溯到起始半径、力度、事件时间和翻转区段。

## 8. 风险与检查边界

- 多球碰撞和库边会改变实际运动时间，纯解析构造只能形成候选解，不能代替真实回放。
