# 数学桌球：九表、多球、六洞实施记录

## 实施范围

以《数学桌球-多关卡配置表分类与字段归属方案》为当前配置契约，通关条件为全部黑球入洞。白球接受玩家输入，碰撞推动黑球。图形不是通关目标，只用于解锁洞或触发道具。

## 配置源

源目录为仓库已有 `Configs/GameConfig/Datas`。`__tables__.xlsx` 明确注册九表，`Defines/billiards.xml` 定义枚举及复合 Bean，使用现有 `gen_code_bin_to_project_lazyload.bat` 导出 cs-bin 和 bin。

| 关卡表 | 内容 |
|---|---|
| Level | 关卡 ID、排序、台面/物理配置引用、杆数、提示开关 |
| LevelBall | 关卡所属球的类型引用、位置、半径；白黑球共表 |
| LevelPocket | 关卡所属六洞槽位及初始状态 |
| LevelProp | 道具参数引用、位置及 Contact/Geometry 触发方式 |
| LevelGeometry | 三角形、变换、唯一内切/外接条件、容差、允许球类型、类型化效果绑定 |

| 复用表 | 内容 |
|---|---|
| Board | Prefab、台面边界、六洞布局与四状态颜色、图形及预测样式 |
| Ball | 球种、Prefab、质量、半径；白球专属击球/尺寸变化 Bean |
| Prop | 道具类型、Prefab、显示直径、触发半径、效果 Bean、使用作用域和次数 |
| Physics | 步长、恢复系数、接触容差、停速、事件次数、预测预算、减速模型 |

主表不重复维护明细 ID 列表、黑球总数或图形总数。全部明细以 levelId 归属本关。运行进度保存在 BilliardsWorld，不写回源表或生成对象。

三个示例关卡按主表 order 排序，通关后“暂停”按钮切换为“下一关”，最后一关返回菜单。重新开始按钮仍重置当前关全部进度。

## 模块职责

- LevelManager：聚合九表，校验同关绑定、图形独占绑定、六洞槽位和可用洞数量，构造关卡快照。
- BallManager：异步加载配置白球和黑球 Prefab，维护实例并同步表现。
- PropManager / PropBase / FlipProp：加载道具、显示使用状态；FlipPropEffect 作为无场景依赖策略供真实世界和预测共用。
- PocketManager / PocketView：管理六洞四状态表现。
- GeometryManager / GeometryView：每个图形只显示配置选择的一个圆，效果完成后隐藏；统一切换提示。
- BilliardsWorld / BilliardsContactSolver：共享时间轴上的连续轨迹接触、球间质量冲量、库边/图形反弹、道具和洞事件。
- BilliardsSession：输入接受、机会消耗、暂停和全部黑球入洞结算，持久进度由世界保存。
- BilliardsBoardView：鼠标投影、球杆、预测虚线和端点圆点；不复制一套简化物理。

## 运行规则与实施默认项

1. 每洞最多收一个黑球。Locked 只能由绑定图形解锁，Occupied/Disabled 关闭洞口且不能再次收球。初始 Occupied 配置不接受。
2. 洞的位置为四角及长边中点，由 Board 的边界和六槽推导，可配置各槽细微 offset、mouthWidth、captureRadius。
3. 单个图形只含一个条件，多个图形可以分别配置内切和外接。几何圆由三角形顶点计算，不在表中重复配置圆心/半径。
4. 不符合条件的球在圆外壁反弹。入口接触时，以世界副本做单次接近查询，仅忽略当前圆障碍，仍保留球碰撞、库边、洞和其他圆；不会递归请求其它圆的放行。当前接近能达到条件时放行，达到条件后触发效果而不反弹。
5. 道具在一杆或整关中的次数根据 Prop.useScope/useLimit 维护。翻转仅改变尺寸趋势。
6. 翻转道具显示直径 .468、触发半径 .234，为原先 .36/.18 的 1.3 倍。
7. 力度控制击球半径、初速和白球无碰撞基准距离 D。减速度为 v²/(2D)，本杆共用此减速度；碰撞后的黑球有自己的实际距离，不把 D 分配给每个球。
8. 球种参数决定质量，半径增长不自动改变质量；球旋转仅是视觉效果，不模拟旋转摩擦。
9. 全部活动球停止后才能出下一杆，保留现有位置、黑球入洞、解锁和整关道具进度；仅重开恢复配置状态。
10. 白球落袋犯规，不占用球洞，也不计入黑球进度。其他球停后放回出生点或最近合法网格空位。默认同杆最后黑球与白球均落袋时，白球复位后按“全部黑球已入洞”通关，不撤回进球；这条是实施默认项。
11. 出杆瞬时放大若与球、边界或有效图形重叠则拒绝出杆并提示降低力度，不消耗杆数。
12. 预测是独立世界副本，显示白球完整反射轨迹；端点为实心圆点，虚线长、间隙、宽度、颜色和圆点大小均由 Board 配置。预算不足不显示虚假的最终停点。
