# 数学桌球：2D 台面与滚动表现修正

日期：2026-10-06。

## 用户确认的玩法方向

俯视的 2D 桌球台面。目标设置在台面上，白球从较远的位置出发，玩家瞄准、蓄力、出杆，白球沿台面滚向目标。球、目标和桌面是世界空间对象；UI 显示按钮、机会、力度和状态。

原版使用 Canvas 上的 Image 白球与 UI 几何绘制，出生点距离目标约 1 单位，无法形成预期的桌球观感。本次改为独立桌球 Prefab，保留已有数学目标、大小变化、翻转道具及三杆规则。

## 实现范围

- 独立 BilliardsTable Prefab，通过资源模块异步实例化，在返回菜单和取消加载时销毁。
- 白球使用 Transform、SpriteRenderer、CircleCollider2D。由现有连续区间模拟控制位置与半径，不引入第二套 Rigidbody2D 运动或库边反弹规则。
- 正交主相机渲染长方形绿毡台面、木质库边、目标、球杆、瞄准线与球体阴影。UI 相机继续渲染操作界面。
- 球面标记按位移除以半径累计滚动相位，产生球体滚动效果；暂停期间相位随模拟一起冻结。
- 瞄准通过主相机屏幕射线投影到台面，保持球、目标和输入统一世界坐标。蓄力后锁定方向，球杆随力量后拉。
- 桌面范围为 16×8；白球 (-5,0)，目标中心 (3,0)，距离 8 单位。目标内切半径 0.6、外接半径 1.2。每杆计划路程 10 单位，速度 4～8，尺寸变化速率 0.12。
- 修改既有 Luban 源表，再调用原导表脚本，禁止手改生成类或 bytes。本任务需要联动修改仓库根目录已有的 Configs/GameConfig 数据源。

## 当前资源和试玩

- 桌球 Prefab：Assets/AssetRaw/Actor/Billiards/BilliardsTable.prefab。
- HUD：Assets/AssetRaw/UI/GameMainUI.prefab，只保留操作和状态。
- 场景：Assets/Scenes/main.unity，正交主相机保留原 UI 相机堆叠。
- 数据源：Configs/GameConfig/Datas/billiards_level.xlsx 与 billiards_ball.xlsx，已通过原导表脚本重新生成。
- 制作工具：Tools/BilliardsTableAuthoring.cs。它负责首次迁移，已有桌球 Prefab 时拒绝覆盖。
- 验证工具：Tools/Billiards2DChecks.cs 和已同步坐标、参数、绑定的 InitialDemo 检查。

在 main 场景点击 Play，再点击“开始游戏”。鼠标对准右侧目标，按住左键蓄力、松开出杆；右键取消，Esc 暂停。目标中心在白球正右方。约 3% 力量可达成内切，满力可达成外接。翻转道具偏离直线路径，需要单独瞄准道具尝试尺寸反转。
