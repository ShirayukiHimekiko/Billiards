## 1. 本版内容

一个关卡、一颗白球、一个三角形目标、一个翻转道具、3杆机会。完成内切或外接任意一种即可通关。暂不制作多关、黑8、钥匙、球袋和反弹。

## 2. 核心规则

| 功能 | 制作要求 |
|---|---|
| 关卡数据 | 由关卡管理器统一读取、校验和提供；目标显示与判定使用同一份几何和容差 |
| 瞄准 | 鼠标移动决定方向，显示台面上的瞄准线和球杆；开始蓄力后方向锁定 |
| 蓄力 | 按住左键逐渐增加力量；达到最大后保持，松开才出杆；右键或取消键放弃蓄力 |
| 出球 | 力量越大，出球越大、初速度越快；最小力量也可以正常击球 |
| 运动 | 沿瞄准方向直线滚动并逐渐减速；没有提前结束时，每杆走相同计划路程 |
| 大小变化 | 起始为变大状态；接触道具后改为变小；变化保持平滑 |
| 大小限制 | 达到允许的最大或最小尺寸后保持；翻转后立即反向变化 |
| 内切成功 | 球位于三角形内，圆周同时贴合三条边 |
| 外接成功 | 球包围三角形，圆周同时经过三个顶点 |
| 判定时机 | 滚动途中持续检查；达成即停球；正常停止时再检查一次 |
| 道具 | 圆周接触触发范围即可，不要求球心经过道具中心；同一道具每杆只生效一次 |
| 出界 | 球体任何部分跨出桌面即本杆失败，包括变大导致的越界 |
| 杆数 | 有效出杆消耗1杆；取消不消耗；失败不再次扣杆；第三杆仍可通关 |
| 复位 | 本杆失败且还有机会时，恢复出生点、变大状态和道具可用状态 |
| 重开 | 恢复3杆，清除旧结果，恢复桌面和白球；滚动中不提供重开按钮 |
| 暂停 | 冻结运动和大小变化，继续后不补算暂停期间的时间 |
| 开始入口 | 应用先显示开始界面；点击开始调用 GameManager，关闭菜单、打开主界面并准备本局，准备完成才允许击球 |
| 退出 | 正常退出应用；Editor 中结束 Play Mode，Player 中退出进程，先作废旧局和清理内容 |

允许少量贴合误差，具体宽松程度通过试玩调整。目标三角形和道具不阻挡白球运动。

## 3. 必要界面

显示剩余杆数、力量条、当前是变大还是变小、目标说明和可隐藏的目标虚线圆。成功显示“内切成功”或“外接成功”；失败区分“离开桌面”和“停下未达成目标”。

本杆失败后给出短提示并复位，也可以立即重试；机会耗尽则显示关卡失败。成功和关卡失败都提供重开、退出。加载异常给出原因和重试入口。

主界面沿用全屏 MainUI，开始界面 StartUI 也为全屏；结果、暂停和加载提示优先组织为主界面内的面板。开始菜单的设置打开非全屏 SettingsUI，仅调整背景音乐、游戏音效、界面音效、声音，见[设置设计](../../功能开发/数学桌球-设置界面与四类音量设计.md)。存档、制作详情继续占位。加载失败属于入口准备异常，不扣杆、不当作关卡失败。

## 4. 必须保留的检查

- 连续点击不会多出杆或多扣杆。
- 道具翻转时，球保持原来的大小。
- 高速经过道具或短暂满足目标时，不会漏掉。
- 成功与失败不会在同一杆重复结算。
- 同刻冲突按出界、成功、道具、停止的顺序处理。
- 暂停、退出和重开后，旧反馈不会再次出现。
- 调整关卡摆放或游戏速度后，仍有正常操作能够完成的解。

## 5. 交付验收

能够完成一次内切、一次外接、一次经过道具的成功尝试；能够连续失败三杆并重开；能够取消蓄力、暂停恢复和退出。界面与实际状态一致，重复游玩流畅，没有明显卡顿。
