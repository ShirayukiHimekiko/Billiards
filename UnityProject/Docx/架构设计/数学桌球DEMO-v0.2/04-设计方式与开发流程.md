## 1. 设计目标

玩家应能理解三个问题：球要往哪里走、到那里时应该多大、是否需要用道具改变大小变化的方向。

方向控制位置；力量影响出球大小和运动速度；道具改变之后是变大还是变小。提示应帮助玩家理解这些关系。

## 2. 怎样设计第一关

1. 先摆好三角形，确定内切和外接两种目标。
2. 设置出生点，让玩家直线击球能够到达目标附近。
3. 先不放道具，确认至少一种方向和力量组合能通关。
4. 加入翻转道具，确认接触时机合适，翻转后的球仍能通关。
5. 加入目标虚线圆和状态提示，再用实际操作检查难度。

第一关推荐使用形状清楚的三角形和一个道具，先让玩家学会机制。具体摆放和大小通过试玩决定。

## 3. 怎样调难度

| 想调整的体验 | 优先调整什么 |
|---|---|
| 总是到不了目标 | 出生点和目标的距离、计划路程 |
| 到达时总是太大或太小 | 出球大小范围、变大变小的速度 |
| 翻转太早或太晚 | 道具位置和触发范围 |
| 看似贴合却很难成功 | 操作敏感度、允许的贴合误差 |
| 玩家看不懂失败原因 | 目标提示、状态文字、失败说明 |

一次只调整一类内容，记录调整前后的结果。关卡必须实际有解，且允许玩家通过正常操作完成。

## 4. 制作和检查顺序

先做击球与大小变化，再做成功判定，再加道具，最后补齐界面与结果流程。每一阶段都保留一个可重复通关的例子。

规则、画面和界面分开负责；可调整的设置集中管理；需要反复出现的对象尽量复用。项目技术实现遵守现有 Unity 和项目框架规范。

完成后检查：两种目标能否识别、三杆流程是否正确、暂停和重开是否可靠、不同运行速度下结果是否一致、目标电脑上是否能稳定达到60帧。性能和手感都以实际测试为准。
