## 2. 球阶段与接触资格矩阵

`TerrainPhase` 为**互斥**阶段，同一球同一时刻只有一个：

`Normal` / `Airborne` / `InTunnel` / `TunnelBlocked` / `TrappedInPit`

### 2.1 各阶段允许的接触类别

| 阶段 | 图形条件 Goal | 道具 Prop | 球洞 Pocket | 地形进入 Terrain | 球-球 Ball | 库边 Rail | 几何门 Gate |
|---|---|---|---|---|---|---|---|
| `Normal` | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ | ✔ |
| `Airborne` | ✔（保留过关判定） | ✘ | ✘ | ✘ | ✘ | ✔ | ✘ |
| `InTunnel` | ✔ | ✔ | ✔ | ✘ | ✔ | ✔ | ✔ |
| `TunnelBlocked` | ✔ | ✔ | ✔ | ✘ | ✔ | ✔ | ✔ |
| `TrappedInPit` | ✔ | ✔ | ✔ | ✘ | ✔ | ✔ | ✔ |

- 判定代码：`TerrainBallState.SuppressesTerrainEntry`（阻止再次进入其他地形触发区）、`TerrainBallState.SkipsGroundObjects`（跳过地面物体接触）。二者是唯一事实来源，不在各规则里重复堆 `if`。
- **`Airborne` 跳过地面物体（含球-球）为方案 §7.1 建议默认**；与旧实现（仅跳过几何门）相比是行为变化，其中"地面球"是方案明列的**确认项**，回退成本为改写 `SkipsGroundObjects` 一处谓词。
- `Goal` 保留：图形条件是过关判定，不是"地面物体"碰撞；飞行中越过目标圆仍应判定命中。
- 库边保留（方案 §7.1 明确"库边保持桌边约束"），故飞行球仍会撞库并改变方向，飞行路程按实际走过的路径长度结算。

### 2.2 出生与落点的接触记录初始化

- 建世界时按出生位置初始化 `TerrainContactBook`：出生点已在触发区内 → 标记 `Inside`，**不**作为进入事件凭空触发。
- 传送落点若仍在出口触发区内 → 立即标记 `Inside`，用于抑制同一时刻回跳。

## 3. 同刻优先级表

沿用方案 §12.4 方向：**先取最早物理时刻，同刻按稳定优先级，再以稳定索引并列**。

### 3.1 普通接触类型顺序（保持不变）

```
Goal → Prop → Pocket → Terrain → TerrainPhase → Ball → Rail → Gate
```

`TerrainPhase` 为**新增**成员，插在 `Terrain` 之后、`Ball` 之前，其余成员的相对次序与旧实现完全一致。

### 3.2 地形事件内部的稳定键

| 事件 | 含义 | 同刻次序 |
|---|---|---|
| `Enter` | 从外到内进入触发区，交由规则处理 | 先 |
| `RegionExit` | 从内到外离开触发区，解锁接触记录 | 中 |
| `PhaseEnd` | 持续阶段结束（落地 / 出隧道 / 通道变径卡住） | 后 |

- 同一时刻的并列以 `球索引 → 地形索引` 为最终稳定键。
- `PhaseEnd` 时刻为正无穷的候选直接丢弃（本段无阶段事件）。
- 冒泡时 `Terrain`/`TerrainPhase` 与 `Goal`/`Prop`/`Pocket` 同刻会让后者优先（保持既有语义）；与 `Ball`/`Rail`/`Gate` 同刻则地形优先。
- **待策划确认（方案 §7.5）**：地形与球洞、道具、三角形真正同刻时的优先级表尚未由策划给出；本轮按上表固定，改动集中在 `EventKind` 枚举顺序与 `MergeTerrain` 的并列判定。

## 4. 五类规则输入 / 输出契约

所有规则实现 `ITerrainRule`：`FindEnter(in BallTrajectory, TerrainPlacementData, TerrainContext)` 与 `Apply(in TerrainHit, TerrainContext)`；规则实例静态无状态，运行态只存在于 `SimulatedBall.Terrain` 与 `TerrainContactBook`。

| 地形 | 进入几何 | 效果 | 结束条件 | 本轮兼容做法 / 待配置项 |
|---|---|---|---|---|
| 跳台 JumpPad | 触发圆，且 `speed > StopSpeed` | `Phase=Airborne`，`PhaseDirection=入速单位向量`，`RemainingDistance=clamp(speed×飞行时间×速度倍率, 最小, 最大)`；**速度大小不变** | 走完剩余路程，或先停球时落地（时间轴事件） | 兼容：飞行时间=`duration`、速度倍率=`speedMultiplier`、最小 0 / 最大 ∞。待配置 `jumpFlightTime/jumpMinDistance/jumpMaxDistance` |
| 隧道 Tunnel | 触发圆，且 `speed > StopSpeed` | `2r` 与内径比较：小 → `Phase=InTunnel` 且速度对齐通道轴、速率保持；等（容差内）→ `TunnelBlocked`、速度清零；大 → 按入口面法线弹开 | 球心越过出口端面 → 出隧道；通道内 `半径` 跨出容差 → `TunnelBlocked` | 兼容：内径=`min(Size)/2`、半长=`triggerRadius`（几何出口，非固定时间）。待配置 `tunnelInnerDiameter/tunnelLength`；**横向偏移/端面朝向严格判定暂缓**（触发圆几何下会误伤正常进入） |
| 地陷 Pit | 触发圆 | `Phase=TrappedInPit`，球心吸附到陷区中心，速度清零；球仍在 `Balls` 中参与球-球接触，永不入洞 | 白球下一杆力度达阈值；任意球受**有效法向冲量**后脱出；整关重置 | 兼容：脱出力度阈值=常量默认 `0.9`（**方案 §7.2 要求归一化阈值、不硬编码最大力度**）；冲量阈值=`0`（方案 §5 契约"任何有效碰撞冲量"）。待配置 `pitEscapePowerThreshold/pitEscapeImpulseThreshold` |
| 反向带 ReverseBelt | 触发圆 | 每次由外到内经过时 `velocity = -velocity`，`|velocity|` 不变；瞬时效果，无持续阶段 | 离开触发区后可再次进入 | 兼容：由接触记录实现"经过一次"，**不再用倒计时** |
| 传送口 Teleporter | 触发圆，且 `speed > StopSpeed`（零速无保向方向） | 速度矢量逐分量保留（`vOut=vIn`）；落点=`出口中心 + 出速方向×(出口触发半径 + 球半径 + 容差)` | 瞬时转移；球离开出口触发区后才允许该口再触发 | 兼容：`inheritVelocity/inheritRotation` 两个开关**不再能关闭**保速保向；出口被占用/越界 → 本次传送取消，球留入口。待配置明确的配对/单向规则 |

### 4.1 卡住与陷住的解除路径

| 状态 | 解除方式 | 明确不做 |
|---|---|---|
| `TrappedInPit` | 白球出杆力度达阈值；任意球有效冲量（且有合法脱出位置）；整关重置 | 不因浮点小速度自动解除；无合法位置时保持陷住并吸收速度 |
| `TunnelBlocked` | 任意球有效冲量（且有合法脱出位置）；整关重置 | **移除**旧实现"速度大于停球阈值即自动解除"的未授权救援 |

- 有效冲量未达阈值、或无合法脱出位置时：吸收该球本次获得的速度，保持卡住/陷住，另一球按解算后速度继续运动。

## 5. 状态所有权

| 数据 | 归属 | 说明 |
|---|---|---|
| `TerrainBallState` | `SimulatedBall` | 互斥阶段 + 阶段方向 + 腾空剩余路程；预测副本必须复制 |
| `TerrainContactBook` | `TerrainSystem` | 每球×每地形实例的 `Inside` 记录，替代旧 `EntryLocked/CooldownRemaining`；一颗球不会锁死整个入口 |
| `TerrainRuntimeState` | 表现层派生 | 只保留"是否高亮"；由球阶段聚合推导，不另存 `Airborne/TunnelActive/Submerged` 三份真相 |
| 地形实例模拟状态 | 无 | 五类当前无证据需要"整个地形进入冷却" |
