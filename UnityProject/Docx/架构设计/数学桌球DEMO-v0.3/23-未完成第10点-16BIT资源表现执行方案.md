# 未完成第 10 点：16BIT 资源表现闭环执行方案

## 1. 当前事实

- `BallBase` 已将连续半径映射到 24 档数值，但仍通过 Transform 缩放单张 Sprite。
- 正常、逆转、冻结、疾变目前主要依赖颜色，没有固定像素状态层。
- `PocketView` 已有盖板状态差异，但没有独立的洞态像素图案资源。
- 球体档位精灵、状态图标、洞态图标和 Prefab 序列化绑定尚未完成。

## 2. 执行步骤

### 步骤 10.1：确定像素资源规格

1. 依据白球配置半径范围制作 20～24 张球体尺寸 Sprite；本项目默认采用 24 档。
2. 统一画布尺寸、像素密度、锚点、透明边界、Point 采样和排序层。
3. 制作正常趋势、逆转趋势、冻结冰壳、疾变标识四类覆盖层。
4. 制作 `Disabled`、`Locked`、`Unlocked`、`Occupied` 四类洞态图案。

### 步骤 10.2：建立资源驱动映射

1. 在 Prefab 中序列化绑定球体 Sprite 档位数组和状态覆盖层。
2. `BallBase` 只根据已校验半径计算档位索引，不在运行时拼接资源路径。
3. 物理碰撞半径继续使用连续值，表现半径只用于渲染和阴影。
4. 半径在上下限时固定使用首尾档位，不能越界访问数组。

### 步骤 10.3：接入白球状态层

1. 正常状态显示基础球面和增长方向标识。
2. 逆转状态显示反向标识，不能只依赖颜色变化。
3. 冻结状态显示冰壳并暂停状态闪烁；疾变状态显示速度/闪光标识。
4. 状态层读取 `BallSimulationComponent` 快照，不直接修改模拟状态。

### 步骤 10.4：接入洞态层

1. `PocketView` 为四态分别绑定图案或盖板资源。
2. 颜色继续由 `PocketStyle` 配置提供，但不能作为唯一识别方式。
3. 洞状态切换时只更新当前实例的 Sprite/Renderer，不修改物理数组。
4. 检查六洞实例的排序层、缩放基准和图案中心一致。

### 步骤 10.5：接入目标环、钥匙和 HUD 图标

1. 目标环使用固定像素尺寸资源或离散档位，避免新增连续缩放锯齿。
2. 钥匙连接线和钥匙图标使用同一像素网格约束。
3. HUD 图标与世界表现共用状态语义，不复制一套颜色含义。

### 步骤 10.6：Pipeline 与收口

1. 使用 Unity Pipeline 创建/导入 PNG、Sprite、Prefab 和序列化数组绑定。
2. 检查导入设置、GUID、Sprite 子资源、Prefab 引用和 Missing Script。
3. 更新执行日志，记录资源数量、导入设置、静态引用检查和提交号。
4. 本点独立提交并推送 `main`。

## 3. 验收边界

- 半径表现使用固定档位资源，不再依赖单张 Sprite 的连续缩放作为唯一表现。
- 四类白球状态和四类洞状态均能在无颜色辅助时保持可区分。
- 物理判定、碰撞半径和几何目标数据不因表现改动而变化。
- 目标环、钥匙和 HUD 图标遵守同一像素规格。

## 4. 依赖与风险

- 依赖第 4 点半径边界规则、第 7 点钥匙资源和第 8 点固定六洞规则。
- 本点需要 Unity Pipeline；未完成资源导入和 Prefab 保存前不能报告为完整实现。
