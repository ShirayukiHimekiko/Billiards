# 数学桌球 DEMO v0.3：玩法说明

## 1. 目标

你操控一颗会改变半径的白球，通过三角形、地形和道具建立正确的几何关系，收集钥匙和其他奖励，让黑 8 全部进入已开启的洞。

## 2. 一杆怎么打

| 操作 | 作用 |
|---|---|
| 移动鼠标 | 调整白球击出方向 |
| 按住力量条 | 增加击球力量，同时决定初始半径、变化速率和速度 |
| 松开 | 出杆，进入滚动阶段 |
| 单键重置 | 无限次恢复整关初始状态，不消耗杆数 |

球滚动时半径会持续变大或变小。状态逆转可以改变变化方向；冻结、复原和疾变会改变一杆或立即改变半径。

## 3. 三角形和目标环

三角形是资源容器。白球接触三角形边界时立即检查内切和外接关系：成功会停球、发放奖励并让三角形消失；失败会弹开，并在球旁显示目标环。

目标环不显示数字。环在球外表示目标半径更大，环在球内表示目标半径更小，环带越厚表示差距越大。同一三角形连续失败 5 次后会首次预亮正确圆，之后每多失败 2 次再预亮一次；成功后计数清零。

## 4. 道具

| 分类 | 道具 | 作用 |
|---|---|---|
| 演化 | 状态逆转、冻结、复原、疾变 | 改变半径趋势、速率或基准值 |
| 信息 | 显影、预演 | 显示几何圆或下一杆预测 |
| 资源 | 加杆、钥匙 | 增加杆数或解锁绑定洞 |

拾取即生效。每关最多出现 4 种道具。

## 5. 地形

| 地形 | 作用 |
|---|---|
| 跳台 | 沿入射方向起飞，飞行中不碰地面物 |
| 隧道 | 球径小于口径通过，等于口径卡住，大于口径弹开 |
| 地陷 | 球陷入，下一杆需要大力打出，也能被其他球撞出 |
| 反向带 | 经过时方向反转 180 度，速率不变 |
| 传送口 | 从配对出口射出，保留速度和方向 |

每关最多使用 2 种地形。地形和道具接触即生效。

## 6. 洞和通关

洞有四种状态：无法使用、上锁、已开启、已进球。钥匙与洞一一绑定，拾取钥匙后立即解锁对应洞。黑 8 全部进洞即通关。

只有杆数耗尽会导致失败。地陷、隧道卡住等局部死局可以用重置全关恢复。

## 7. 画面提示

左上显示持续效果，右上显示杆数，底部显示分段力量条。常态、逆态和冻结球使用不同的形状与颜色组合；洞的四种状态使用固定像素标识，保证小尺寸下也能区分。
