# 未完成第 11 点：HUD 完整信息结构执行方案

## 1. 当前事实

- `MainUI` 已显示剩余杆数、剩余黑球、大小趋势、通用道具状态和力量条。
- `SessionUISnapshot` 已有预演次数和启用状态字段，但 `MainUI` 尚未展示。
- HUD 没有持续效果时效、冻结/疾变状态、六洞四态、钥匙绑定、钥匙收集和半径曲线。
- 现有 `PredictionPropWidget` 的手动反射轨迹开关不能直接等同于 v0.3 预演信息区。

## 2. 执行步骤

### 步骤 11.1：定义唯一 HUD 数据契约

1. 扩展会话快照，统一提供杆数、黑球数、半径趋势、半径档位、持续效果和预演状态。
2. 增加六洞状态快照、钥匙总数/已拾取数和钥匙绑定关系。
3. 增加一次性反馈事件与持续状态的区分，避免拾取提示覆盖持续效果。
4. 快照只由 `Session`、`PhysicsWorld`、`PocketManager` 和道具状态组装，UI 不直接读物理对象。

### 步骤 11.2：扩展 MainUI 序列化绑定

1. 在 UGUI Prefab 增加状态图标槽、时效进度槽、洞态列表、钥匙列表和预演面板。
2. 使用项目现有节点前缀和生成绑定机制，不在代码中 `Transform.Find` 或运行时补组件。
3. 为移动端确定优先级：杆数、黑球进度、当前球状态和重置入口必须保持可见。
4. 对过长文案和多洞状态采用固定尺寸图标与短标签，避免遮挡力量条。

### 步骤 11.3：显示白球与道具持续状态

1. 显示增长/缩小趋势和离散半径档位，不能显示会泄露几何答案的内部数值。
2. 显示逆转、冻结、疾变图标及剩余杆数/进度。
3. 道具到期时移除图标并恢复基础状态；重置、失败、通关和离开关卡时清空。
4. 一次性道具显示短暂拾取反馈，不占用持续状态槽位。

### 步骤 11.4：显示预演信息

1. 预演未启用时显示不可用/未拾取状态，不能把普通预测轨迹伪装成预演。
2. 启用后显示下一杆轨迹、目标接触点和半径变化趋势曲线。
3. 当前状态和下一杆预演使用不同颜色/边框/标题，避免混淆。
4. 预演消耗、取消和到期由会话事件驱动，UI 不修改消耗次数。

### 步骤 11.5：显示洞态与钥匙状态

1. 固定显示六洞图标，使用四态图案表达 `Disabled`、`Locked`、`Unlocked`、`Occupied`。
2. 钥匙图标显示已拾取/未拾取及对应锁洞，洞解锁后同步更新。
3. 黑球进度与洞态列表保持同一快照刷新，不能出现先后帧不一致。
4. 不直接显示内切/外接数值答案或判定容差。

### 步骤 11.6：接入生命周期并通过 Pipeline 保存资源

1. 进入关卡、重置、暂停、失败、通关、下一关和返回选关时刷新或清空 HUD。
2. 通过 Unity Pipeline 修改 HUD Prefab、节点绑定和图标资源。
3. 检查生成绑定代码、Prefab 序列化引用、布局锚点和窄屏溢出。
4. 更新执行日志，本点独立提交并推送 `main`。

## 3. 验收边界

- HUD 能显示当前球状态、持续效果、预演状态、杆数、黑球数、六洞状态和钥匙状态。
- HUD 所有数据来自统一快照/事件，不直接驱动物理或通关逻辑。
- 重置、失败、通关和切关后不存在残留图标、计时器或旧洞态。
- 移动端主要信息不遮挡，Prefab 绑定无 Missing Reference。

## 4. 依赖与风险

- 依赖第 2 点道具状态、第 7 点钥匙资源、第 8 点六洞固定、第 10 点像素资源。
- 需要在 HUD Prefab 可通过 Pipeline 正常编辑和保存后，才能完成本点资源验收。
