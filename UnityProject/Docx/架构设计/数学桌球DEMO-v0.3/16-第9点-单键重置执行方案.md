# 第 9 点：单键重置执行方案

## 1. 目标

在保留现有 `Session.Restart()` 的前提下，增加 v0.3 要求的单键无限次重置。重置不消耗杆数、不增加悔棋语义，并能解除地陷、隧道卡住等局部死局。

## 2. 当前实现与差异

- 当前 `Session.Restart()` 已能重建 `PhysicsWorld`、杆数和场上状态。
- 当前主要通过 `MainUI.OnClick_RestartBtn()` 触发，没有单键输入入口。
- 新增地形、钥匙、反馈和持续道具后，现有重置清理项需要扩展。

## 3. 执行步骤

1. 确定演示平台的单键和输入映射，将输入绑定到会话命令，不在 UI 类中直接实现业务重置。
2. 让键盘/手柄和现有 UI 按钮共用同一个重置命令，避免两套流程产生不同状态。
3. 重置前取消滚动、反馈环、预亮、持续道具、地形状态和延迟事件；重建后恢复配置快照。
4. 明确暂停、失败、通关和异步加载期间的重置状态边界，避免旧场景回调写入新场景。
5. 保证重置不消耗杆数、不改变关卡选择、不产生悔棋历史。
6. 检查所有新增模块是否都实现统一的重置清理入口。

## 4. 影响范围

输入映射、`Session`、`MainUI`、`PhysicsWorld`、洞/钥匙、道具、地形、几何反馈、HUD 和异步生命周期。

## 5. 依赖与待确认

- 依赖第 3、5、6、7 点明确各自的状态和回调清理项。
- 需要确认单键是键盘固定键，还是由输入配置表映射。
- 需要确认通关后是否允许重置回到本关，方案默认允许但不改变选关进度。

## 6. 交付边界

本方案复用现有重置入口，不新增悔棋、历史快照或局部撤销系统。
