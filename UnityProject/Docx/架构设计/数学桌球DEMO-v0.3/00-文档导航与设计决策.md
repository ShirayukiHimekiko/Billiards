v0.3 是当前策划方向。它替代 v0.2 的单白球、三杆尝试和翻转道具方案，也替代 2026-10-06 的黑球与六洞候选方案。v0.2 文档和既有验收记录保留为历史资料，不与本目录混合引用。

| 项目 | v0.3 决策 |
|---|---|
| 设计支柱 | A 几何洞察、C 可控的意外 |
| 核心目标 | 通过几何关系获取资源，把黑 8 全部送入已开启的洞 |
| 失败条件 | 仅杆数耗尽 |
| 重置 | 单键无限次重置全关，移除悔棋 |
| 三角形 | 资源容器；命中后立即停球、发放奖励并消失 |
| 洞 | 无法使用、上锁、已开启、已进球四态 |
| 道具 | 8 项，每关最多 4 种 |
| 地形 | 5 项，每关最多 2 种 |
| 反馈 | 未命中显示同心目标环；同一三角形失败达到阈值后预亮 |

## 3. 已确定的规则

- 白球半径由本杆力量决定，滚动中按方向和实际速率线性变化，并限制在 `[rMin, rMax]`。
- 三角形内切和外接都属于可命中几何解；球接触三角形边界时立即判定，不等自然停球。
- 命中成功后球立即停下，发放三角形奖励并移除三角形；未命中则作为实体障碍弹开。
- 跳台腾空期间不与地面三角形碰撞；地形和道具接触即生效。
- 拾取道具即生效，不提供独立使用动作；每关最多出现 4 种道具和 2 种地形。
- 黑 8 全部进入已开启的洞才通关；钥匙与洞一一绑定，拾取钥匙立即解锁对应洞。
- 只有杆数耗尽会失败；地陷、隧道卡住等局部死局通过重置全关脱困。

## 4. 待评审项

以下内容来自策划案第 15 节，当前必须保留为待定，不得在实现文档中擅自定案：

1. 半径触及上下限后停住还是反向。
2. 只按半径判定是否会造成多角度误命中。
3. 显影和预演是关卡奖励还是按需帮助按钮。
4. 地陷中球的取出方式与力度参数。
5. 传送口配对数量和可视规则。
6. 关卡结构设计。
