# 数学桌球 DEMO v0.3：程序向功能策划文档

> 本文是程序行为契约和数据设计，不是已经完成的实现清单。

## 1. 半径与速度

```text
r(t) = r0 + s * k_eff * t
r0 = Lerp(rMin, rMax, P)
K  = Lerp(kMin, kMax, P)
V  = Lerp(vMin, vMax, P)
k_eff = 0（冻结）| 2K（疾变）| K（常态）
```

半径始终限制在 `[rMin, rMax]`。触及边界后停住还是反向属于待定项，边界行为不得由不同模块各自决定。

## 3. 判定流程

```text
OnContact(ball, triangle):
    if ball.Airborne: return
    dIn  = Abs(ball.R - triangle.InRadius)
    dOut = Abs(ball.R - triangle.CircumRadius)
    if Min(dIn, dOut) <= eps:
        stop ball
        grant triangle reward
        consume triangle
        clear fail count
    else:
        bounce ball
        target = dIn < dOut ? triangle.InRadius : triangle.CircumRadius
        FeedbackRing.Show(ball.Pos, target)
        HintDirector.OnFail(triangle)
```

## 4. 参数基线

| 参数 | 初始值 |
|---|---:|
| `vMin` / `vMax` | 3 / 12 |
| `rMin` / `rMax` | 0.3 / 2.4 |
| `mu` | 0.6 |
| `eps` | 0.08 |
| `flyFactor` | 2.5 |
| `hMax` | 2.0 |
| 半径精灵档位 | 20～24 |

这些值是 v0.3 策划基线，后续由关卡调优确认；边界反向、地陷力度等待定行为不能从参数表推断。

## 5. 关卡数据示例

```json
{
  "levelId": "L01",
  "shots": 8,
  "ball": { "start": [0, 0] },
  "triangles": [
    { "v": [[1, 1], [4, 1], [2, 3]], "reward": "key", "param": 1 }
  ],
  "items": [
    { "type": "freeze", "pos": [2, 2] }
  ],
  "terrain": [
    { "type": "jump", "pos": [3, 3], "param": {} }
  ],
  "holes": [
    { "pos": [5, 5], "state": "locked", "keyId": 1 }
  ],
  "eightBalls": [
    { "pos": [6, 6] }
  ]
}
```

关卡数据必须校验三角形不退化、半径和容差有效、洞钥匙引用存在、道具种类不超过 4 种、地形种类不超过 2 种。缺失或非法数据应在关卡准备阶段暴露原因，不用硬编码默认关卡静默替换。

## 6. UI 数据

`HudView` 只读当前运行快照：剩余杆数、力量、球的演化状态、冻结/疾变/预演等持续效果、洞态和目标环反馈。UI 不直接修改 `BallRuntime`，操作通过 `LevelController` 的明确入口提交。
