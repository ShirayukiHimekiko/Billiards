## 使用顺序

1. 查看 `previews/开始界面效果图.png`，确认深蓝、木质边框的像素风格和左侧菜单布局。
2. 用 `sprites/start_menu_background.png` 作为正式 UI 的无文字背景。
3. 用 `sprites/start_menu_button_normal.png` 和 `sprites/start_menu_button_pressed.png` 作为五个按钮共享的底图。
4. 标题“数学桌球”和“开始、设置、存档、制作详情、退出”分别由独立文字组件呈现。

效果图是一张静态设计示意，不能直接充当可交互 UI 或运行截图。正式菜单的坐标、组件、字体和适配要求以设计文档为准。主题背景里的几何形状只作装饰，不用于玩法判定。
