# 嵌入式包目录命名警告修复

## 原因与检查结果

任务等级：L2（包目录配置排障）。

Unity 提示嵌入式包所在目录名称与包的 package.json 中 name 不一致。
已检查两个包的清单：UniTask 的 name 为 com.cysharp.unitask，YooAsset 的 name 为 com.tuyoogame.yooasset。
当前 Packages/manifest.json 没有直接声明这两个包；嵌入式包可以由 Unity 自动发现。
排除缓存、日志及生成的 IDE 项目文件后，旧目录路径引用只在 Packages/packages-lock.json 中发现，分别为 file:UniTask 和 file:YooAsset。

## 修复步骤

1. 保存当前编辑内容并关闭该项目的 Unity Editor。
2. 将 Packages/UniTask 整个目录重命名为 Packages/com.cysharp.unitask。
3. 将 Packages/YooAsset 整个目录重命名为 Packages/com.tuyoogame.yooasset。
4. 保留目录内全部文件及已有 .meta；保持 package.json 的 name 和版本不变。
5. 重新打开项目，等待 Unity Package Manager 重新解析包并更新 packages-lock.json。

无需为这两个嵌入式包额外添加 manifest.json 依赖，也无需清理 Library。

## 验证

- Package Manager 仍能识别 UniTask 2.5.10、YooAsset 2.3.17。
- packages-lock.json 对应条目的 source 仍为 embedded，version 路径与新目录一致。
- 本轮不再产生这两条目录命名警告，且无新增编译错误。
- Console 原有记录可能仍显示；应区分历史日志与重新打开项目后的新日志。
