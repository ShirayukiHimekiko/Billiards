# 数学桌球：关闭游戏白球销毁异常修复

日期：2026-10-06。

## 原因

退出 Unity Play Mode 或关闭应用时，场景对象与框架销毁回调的顺序无法保证。白球可能先被销毁，随后 GameApp.Release → GameManager.Cleanup → BilliardsSession.Release 仍调用 Simulation.Stop，后者通过 BallBase.ApplyState 更新已经失效的 Transform，产生 MissingReferenceException。

## 修正

- BilliardsSession.Release 先作废会话和积累时间，重复调用立即返回。
- 对白球和功能组件使用 Unity 的对象有效性判断；仍存活时解绑输入、复位模拟，不调用会刷新画面的 Stop。
- GameManager 和 LevelManager 清理台面时用 Unity 的对象比较，避免 ?. 无法识别已销毁 Unity 对象的问题。
- 台面释放允许 Runner 已先被销毁。
- 正常滚动、成功和失败仍使用 Stop 更新停球画面。

## 验证范围

目标实例：UnityProject，Unity 6000.5.10f1，main 场景。仅修改普通 C# 与文档，不修改 Scene、Prefab 或工程设置。

- Unity 编译完成，无编译错误。
- BilliardsShutdownChecks 四种情况均通过：正常返回菜单、白球先销毁、球面子对象先销毁、完整台面先销毁。
- 每种情况都实际等待对象销毁，再调用会话清理；重复 Release、Tick、出杆与返回菜单不会报错，白球和台面无残留。
- 出杆后直接停止 Play 通过，原始 GameApp.Release → GameManager.OnRelease 清理链不再报错。
- 主界面实际退出按钮通过，确认结束 Play。
- 与修复前 Console 游标对比，没有新增错误；Unity Console 当前错误数为 0。
- 收尾保留 main 场景，Unity 回到编辑模式。没有构建独立 Player，本次直接关闭验证在 Editor 完成。
